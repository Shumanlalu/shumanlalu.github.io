Which APK should I install?
Most modern Android phones use ARM64. Use ARMv7 only for older 32-bit devices. x86_64 is mainly for emulators. If Android refuses an APK, try the other architecture without uninstalling the app.

Installation instructions

Download the correct APK

Tap the Download button above. Keep the browser open until the file finishes.

Open the file

Android may warn that the source is unknown. This is normal for a direct APK install.

Allow this source

When prompted, allow your browser or file manager to install APKs, then tap Install.

Verify when possible

Compare the SHA-256 shown above with the downloaded file. On Windows PowerShell use Get-FileHash .\file.apk -Algorithm SHA256.

Do not uninstall to downgrade

Uninstalling deletes the app's encrypted local messages. Upgrade normally instead.

NEXCHAT requires Android 8.0 (API 26) or later. The APK is installed through Android's official installer; the website has no permission to install apps silently or read your messages.
