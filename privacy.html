Privacy policy

This policy covers the public NEXCHAT website only. It does not replace any privacy terms inside the messaging application or backend service.

1. What this website does

The website introduces NEXCHAT, publishes release information and serves Android APK files. It has no user registration, no public dashboard and no database connection.

2. Information collected

The site does not ask for personal information through forms. Contact links open your own email app. The hosting provider may keep standard technical request logs such as IP address, browser type and requested URL, subject to its own policies.

3. APK downloads

Downloading an APK is a direct file request. The website does not require an account to download and does not track message content. Published SHA-256 values let you verify the file you received.

4. Advertisements

Advertising areas are clearly labelled. No third-party advertising network is enabled by default. If a network is configured later, that network may collect data under its own privacy policy; this website will keep the placement label visible.

5. Messaging data

NEXCHAT message content is encrypted on device with the Signal protocol. This promotional website cannot access accounts, conversations, keys or files stored by the app.

6. Contact

Questions about this policy can be sent to the configured contact address.

7. Changes

This policy may be updated when the website's behaviour changes. The publication date below identifies the current version.
