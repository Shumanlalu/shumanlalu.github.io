App features

Capabilities, stated accurately.

These are features present in the NEXCHAT codebase. Where a capability still needs physical-device verification, this page says so explicitly.

⌁

Signal protocol

X3DH/PQXDH sessions and the Double Ratchet. No custom cipher.

Implemented
◇

Private groups

Pairwise encrypted delivery to every member device and server-side membership checks.

Implemented
↻

Durable outbox

Encrypted local queue, exponential retry, deduplication and reconnect sync.

Implemented
◎

Safety numbers

Per-device numeric fingerprints, QR display/copy and identity-change alerts.

Implemented
▤

Encrypted files

Chunked attachments with validated manifest, conversation binding and size bounds.

Implemented
◉

Voice and video calls

WebRTC call signaling inside encrypted content. TURN is available when configured by the operator.

Implemented
≋

Nearby Bluetooth relay

Bluetooth Classic RFCOMM with encrypted routing headers and bounded flooding.

Real-device testing pending
⚿

Encrypted local storage

SQLCipher database with the passphrase wrapped by Android Keystore AES-GCM.

Implemented
⚑

Operator controls

Private admin panel for accounts, sessions, remote configuration and announcements.

Implemented

Current limitations

AreaStatus
Push notificationsNot included. A foreground service keeps the connection alive.
Public sign-upNot offered. Accounts are provisioned by the operator.
Nearby relayAutomated checks pass; two-phone Airplane Mode and three-device relay tests are still required.
TURN callingOnly active when the operator configures a TURN shared secret.
Installer note: Android will ask you to allow installation from this source. NEXCHAT never installs silently. Uninstalling the app deletes its local encrypted messages, so upgrade normally instead.
